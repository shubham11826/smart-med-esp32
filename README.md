# smart-med-esp32
Smart Medicine Dispenser and reminder using ESP32 and Web Interface

## Overview
This project is a Smart Medicine Dispenser using **ESP32** that helps patients take medicines
on time using an automated reminder and web-based interface.

## Hardware Components
- ESP32
- DC Motor
-IR Sensors
- Buzzer
- LED
- LCD Display
- Power Supply

## Software & Technologies
- Arduino IDE (ESP32)
- HTML, CSS, JavaScript
- Embedded C++

## Project Structure
smart-medicine-esp32/
├── esp32_code/ → Arduino (.ino) code
├── frontend/ → Web interface files
├── images/ → Circuit & project images
├── docs/ → Project report

## How It Works
1. ESP32 controls the medicine dispenser
2. Web interface allows setting medicine time
3. ESP32 triggers alerts and dispenses medicine
4. Buzzer/LCD provides notifications

## How to Run
1. Open `.ino` file in Arduino IDE
2. Select **ESP32 Board**
3. Upload code
4. Open `index.html` in browser
5. Connect ESP32 to same network

## Output
- Timely medicine reminders
- Automated dispensing
- Web-based control panel
